## Rules-correct visible opening (user-requested fix)

Source checked: USBGF Backgammon Basics / Movement of the Checkers, https://usbgf.org/backgammon-basics-how-to-play/. Each side rolls one die; tied rolls are repeated for both; the higher roller starts using precisely those dice. No replacement two-die roll or cube choice precedes the first checker move.

The native engine already implements those rules in NewGame, but the adapter automatically resolved/autoplayed the opening before presenting the game. Add durable opening_roll and opening_result phases: explicit opening action, per-color results and tie attempts, acknowledgment before any first checker/bot move. Both new matches and subsequent games use this flow. Persist exact native dice/checkpoint and pin all existing engine/profile settings. Legacy in-progress sessions remain resumable.
