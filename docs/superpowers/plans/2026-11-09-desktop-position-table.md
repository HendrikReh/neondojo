# Desktop position research table

**Goal:** Bring compact, resizable, sortable columns and one contextual row tooltip to the Position Browser while retaining its board preview, saved searches, analysis and learning/Anki transfers.

**Design:** Show distinct on-roll player and opponent columns, dice, score/cube, game/ply, database, numeric match identity/origin, native loss, notes and the existing analysis action. Make the on-roll player filter prominent so exact-position/dice searches can answer how a named player such as Mochy played. The current on-roll semantics remain unchanged and are regression tested for both player colors. Offer recorded played moves as an optional column, initially hidden; no best-move answer is exposed. Before-move board preview remains available on row selection beside the table.

Reuse the existing tested column resizing behavior through a shared configurable model/hook; retain the match library's persisted keys/layout unchanged and store position widths separately. A global reset restores responsive defaults. Use the full desktop window with a readable fixed-width preview and an independently scrolling compact table. Localized row summaries carry complete player/context/provenance and bounded notes without competing cell titles.
