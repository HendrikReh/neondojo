# Playing history review

User scope: history must be clickable and keyboard navigable like Analysis. Add read-only review backed by canonical SGF snapshots, not a reconstructed guess from the flattened log. Preserve native session/version/checkpoint and local unconfirmed checker steps. Click/Enter/Space selects a row; Up/Down moves and scrolls selected item. Initial/Arrows/Final plus Left/Right mirror Analysis. Return to game restores the exact current local/native decision. Live actions are disabled synchronously while reviewing/loading; do not interrupt native actions/animations.

Backend task: GET /api/play/sessions/{id}/history?version=N returns {session_id,version,items:[{index,game_no,move_no,kind,before:Position,after:Position}]}, one item per native history record. Read one atomic saved checkpoint; require requested version match409. Parse normalized saved native SGF including multiple games, cube actions, pass/hit/bearoff/resignation; raw data unchanged and no native process/RNG. Share existing strict source parser, extend internal SourceMove after-state if necessary. Support detached library sessions. Unit/integration proof, no main DB writes/restart.

Frontend task: cached/abortable review load keyed by session ID/version, safe rapid selection; interactive history with roving focus and own scroll; existing read-only API. Board review and controls visible without changing live steps/order, scores or server state. Preserve view while switching rows. Loading/errors/return handle cache conflicts. Legacy mocked histories without endpoint should fail clearly and still return to live play. Test action suppression, restoration of partial turn, keyboard, stale responses and layouts; build, review, verify local deployment.

Completed and deployed to the local server on port 8787. Verification: 20 browser cases covering interaction, pending-turn restoration, loading/cancellation/errors and layout; 2 actual GNUbg browser cases covering both colors/directions and 0/2-ply; 17 native backend cases plus 6 history cases; 313 frontend unit tests; 92 backend unit tests (26 optional cases ignored). Production build and generated OpenAPI types pass. Independent frontend/backend reviews found no actionable issues. Read-only live verification loaded all 3 existing session histories and exercised the 73-entry history with mouse and arrow keys. All saved checkpoint columns remained identical across graceful restart and verification. Evidence and screenshots are in ignored backups/play-history-review-20261109. Disposable test database and task-owned servers were removed.
