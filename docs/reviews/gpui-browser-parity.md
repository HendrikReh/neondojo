## Follow-up on the two P1 issues

**Analysis.** On the first WC2014 checker decision, GPUI and React both show XG equity **+0.014604** with **Opening Book V2** and GNUbg equity **+0.015127** at **1-ply** for the played move 24/18 13/11. The GNUbg–XG difference is **+0.000523**. For 24/16 the imported equity is **−0.010413** and its loss against the XG best is **0.025017**. The browser candidate view rounds that loss to **0.025**. The native candidate view also reproduces the six browser outcome percentages. Missing evaluations remain missing, and cross-source differences require compatible equity units. [Issue #228](https://github.com/HendrikReh/neondojo/issues/228)

**Library.** On the baseline, the browser finished a ten-game analysis while the open native row still showed Queued. With the fix, a two-match GNUbg batch submitted in React updated the native Library while it stayed open. Both clients showed Queued, Running and Completed for the same job. Both test-database notification listeners were disconnected while it was running. They reconnected, and the row reached Completed without a user refresh. The watched job finished 10 of 10 games, and the browser batch counter reached 2 of 2. [Issue #229](https://github.com/HendrikReh/neondojo/issues/229)

## Findings during PR review

- **Analysis sources and units.** The native catalog now scopes position jobs before pagination. Moving between checker positions discards old pages and cursors. Both clients use the equity unit recorded for the calculation, including cubeless GNUbg analysis. They omit comparisons when a legacy result's unit cannot be established.
- **Library progress.** A game or position job now refreshes its owning match, which can show **Partial** as soon as that result commits. The match row and bulk panel read the same database snapshot when both are visible. The PostgreSQL reconnect regression runs in the default backend CI suite.
- **Notes.** The inspector and Move notes dialog share drafts by annotation target. Switching matches or closing the dialog preserves unsaved text, including a paste over the save limit. A delayed conflict response cannot replace another target’s draft.
- **Positions.** A failed or unreadable result page clears its decision references, preview and deck actions. The bookmark button reads membership for the selected occurrence before choosing Save or Remove.
