# NeonDojo documentation

NeonDojo is a local backgammon study app for Apple Silicon Macs. Import matches, review checker plays and cube decisions, and practice positions from your own games.

[Install NeonDojo](https://github.com/HendrikReh/neondojo/blob/main/README.md#quick-start) or open the [illustrated user guide](user-guide/README.md) for a walkthrough of every workspace.

## Feature reference

| To… | Open |
| --- | --- |
| Play a match or money session against an engine | [Playing](reference/playing.md) |
| Review a move, compare candidates, or analyze a match | [Analysis](reference/analysis.md) |
| Import matches, find positions, or manage players | [Match library, positions and players](reference/library.md) |
| Practice recurring mistakes or review flashcards | [Study](reference/study.md) |
| Configure engines, profiles, or board artwork | [Settings](reference/settings.md) |
| Run an engine duel or back up your database | [Extras](reference/extras.md) |
