# Einheitliche Aktions-Icons

Empfehlung: [Lucide Outline](https://lucide.dev/icons/). Die Bibliothek bietet ein einheitliches SVG-Set; Referenzraster 24 × 24, Strichstärke 2. Quelle: [Lucide Guide](https://lucide.dev/guide/). Die appweite Einführung ist umgesetzt: kompakte Routineaktionen mit Icon und Tooltip, wichtige Spielaktionen und primäre Formularaktionen mit Icon und Text. Tooltips erscheinen bei Hover und Tastaturfokus.

| Benutzeraktion | Lucide-Icon | Bedeutung |
| --- | --- | --- |
| Speichern | [save](https://lucide.dev/icons/save) | Änderungen speichern |
| Undo / Schritt zurück | [undo-2](https://lucide.dev/icons/undo-2) | Letzten unbestätigten Schritt zurücknehmen |
| Hint / Hinweis | [lightbulb](https://lucide.dev/icons/lightbulb) | Unterstützung zur aktuellen Entscheidung |
| Löschen | [trash](https://lucide.dev/icons/trash) | Ausgewähltes Element löschen |
| Hinzufügen | [plus](https://lucide.dev/icons/plus) | Neues Element anlegen oder hinzufügen |
| Exportieren | [download](https://lucide.dev/icons/download) | Datei aus BG Tutor herunterladen |
| Importieren | [upload](https://lucide.dev/icons/upload) | Datei in BG Tutor übernehmen |
| Spiel fortsetzen | [play](https://lucide.dev/icons/play) | Gespeichertes Spiel fortsetzen |
| Öffnen | [folder-open](https://lucide.dev/icons/folder-open) | Vorhandenes Match oder Datei öffnen |
| Suchen | [search](https://lucide.dev/icons/search) | Bestand durchsuchen |
| Bearbeiten | [pencil](https://lucide.dev/icons/pencil) | Bestehende Angaben ändern |
| Kopieren | [copy](https://lucide.dev/icons/copy) | Eine Kopie erzeugen |
| Aktualisieren | [refresh-cw](https://lucide.dev/icons/refresh-cw) | Aktuellen Zustand erneut laden |
| Einstellungen | [settings](https://lucide.dev/icons/settings) | Konfiguration öffnen |
| Schließen / Abbrechen | [x](https://lucide.dev/icons/x) | Aktuelle Ansicht schließen |
| Bestätigen | [check](https://lucide.dev/icons/check) | Auswahl oder Änderung bestätigen |

Darstellungsregeln: einheitlich 20–24 px, 2 px Linienbreite, abgerundete Linienenden, Farbe vom Buttontext übernehmen. Auf primären Aktionen Icon und Text gemeinsam zeigen; reine Icon-Buttons nur für gut bekannte, platzkritische Aktionen mit verständlichem zugänglichem Namen und Tooltip. Klickflächen mindestens 44 × 44 px. Rot für destruktive Aktionen, Akzentfarbe für die aktuell mögliche Hauptaktion, deaktivierte Aktionen weiterhin erkennbar. Keine Mischung mit Emoji- oder gefüllten Symbolen.
